# Sparkle Schemer

A visual bedazzling planner for mapping rhinestone patterns before placing them.

## Current features

- Square and honeycomb grid layouts
- Adjustable rows, columns, and stone spacing
- Ten-color rhinestone palette
- Click-and-drag painting and erasing
- Live stone and color counts
- SVG export
- Responsive, keyboard-accessible controls

## Run locally

Requires Node.js 22.12 or newer.

```bash
npm install
npm run dev
```

Vite will print the local development URL. To create and preview a production
build:

```bash
npm run build
npm run preview
```

Run the test suite with:

```bash
npm test
```
